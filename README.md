# 📊 Customer Churn Prediction using Deep Learning

My **first Deep Learning project** — a small end-to-end project to understand how neural networks can be used for a real-world classification problem.

The goal of this project is to predict whether a customer is likely to **churn (leave the service)** based on their available customer information.

This project marks the beginning of my **Deep Learning journey**, where I am learning and implementing concepts step by step.

---

## 🎯 Project Objective

Customer churn is an important problem for businesses because retaining existing customers is often more valuable than acquiring new ones.

In this project, I use a **Neural Network** to predict:

* `0` → Customer will stay
* `1` → Customer will churn

## 🏗️ Neural Network

The project uses a simple **Artificial Neural Network (ANN)** for binary classification.

Basic architecture:

```text
Input Features
      ↓
Input Layer
      ↓
Hidden Layer
(ReLU Activation)
      ↓
Hidden Layer
(ReLU Activation)
      ↓
Output Layer
(Sigmoid Activation)
      ↓
Churn Prediction
```

The output represents the probability of customer churn.
